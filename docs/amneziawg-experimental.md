# Экспериментальная поддержка AmneziaWG

Поддержка находится на стадии испытаний. По умолчанию она выключена. Для
проверки в настройках Forkop включите «AmneziaWG: экспериментальная поддержка»,
сохраните изменения и перезапустите Forkop. Один параметр
`forkop.settings.awg_experimental` используется и интерфейсом импорта, и
службой; значение `1` включает режим, отсутствие или `0` выключает.

Режиму необходимы совместимые с установленным ядром OpenWrt пакеты
AmneziaWG, инструменты `awg` и `ip` с поддержкой JSON. Установщик
`scripts/install-awg-dependencies.sh` предназначен только для официального
OpenWrt 25.12.6 mediatek/filogic и проверяет пакетные зависимости до установки.
Не обходите проверку ABI ядра.

Для ручного профиля откройте нужное правило типа «Подключение», выберите
импорт `.conf` и дождитесь результата, затем перезапустите Forkop для сборки
маршрутизации. Импорт создает интерфейс и может ненадолго прервать связь.
Передайте файл через LuCI по HTTPS; он содержит приватный ключ. Замена уже
активного ручного профиля пока не поддерживается.

Фоновая задача удаляет временный файл после чтения. При аварийном завершении
она может оставить блокировку и неопределённое состояние сети. До повторной
попытки проверьте интерфейсы и конфигурацию. На системе с `/tmp` в tmpfs
перезагрузка очищает временную блокировку, но не отменяет уже записанные UCI
настройки; проверьте их отдельно. Выключение режима сохраняет ранее созданный
firewall guard при перестроении таблицы, пока существует его snapshot.

CI проверяет отдельные компоненты и синтетические данные. Совместимость с
конкретной прошивкой, поведение при изменениях сети и проверка handshake на
физическом роутере или в OpenWrt VM требуют отдельного испытания.
