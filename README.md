# ArtakFork

Форк [Screamshow/forkop-x](https://github.com/Screamshow/forkop-x) без ограничения подписок по провайдеру. Базовый коммит: `2a0951294d9cdd24370ff97fc1bc09fcb8b7f484`.

Версия **2.4.3-canary.8** готовится как тестовый выпуск с экспериментальным
первым импортом AmneziaWG 2.0 и 3.1 из `.conf` и подписки панели, включая
списки с VLESS. В LuCI включите **«AmneziaWG: экспериментальная поддержка»**
в настройках Forkop, сохраните настройки и перезапустите Forkop. Для файла
используйте кнопку **«Импорт AmneziaWG .conf»** в нужном правиле подключения.

Автоматическое переключение уже активной подписки AmneziaWG пока отключено:
обновление ставится в очередь, а действующее подключение сохраняется. Поддержка
ещё требует проверки первого импорта и маршрутизации в OpenWrt VM и на целевом
роутере. Подробнее — [условия и ограничения тестовой версии](docs/amneziawg-experimental.md).
Установщик добавляет зависимости AmneziaWG только для OpenWrt 25.12.6 на
`mediatek/filogic`; на остальных поддерживаемых установщиком целях ArtakFork
ставится без них.

В версии 2.4.3-canary.7 сообщение об ошибке пустой URLTest-группы содержит режим фильтра и безопасные имена доступных кандидатов. Настройка **Приоритет** позволяет явно задать основной и резервный узлы; прямое соединение используется только при его явном добавлении. Если основного узла больше нет, группа может использовать заданный резерв. При отсутствии подходящих узлов конфигурация не применяется.

На карточке узла или группы доступна проверка HTTPS для ChatGPT, Gemini и Discord через выбранный узел. Проверка запускает отдельный процесс sing-box на срок до 15 секунд и не меняет историю URLTest. Полученный HTTPS-ответ не подтверждает HTTP-статус, доступность в стране или вход в аккаунт.

После ручного обновления подписок отчёт показывает по источникам добавленные, удалённые, переименованные и изменённые соединения и доступные категории пропущенных записей. Имена, похожие на секреты, скрываются. Отчёт описывает полученные данные; при ошибке они могут быть не применены.



В версии 2.4.3-canary.4 устранена также проверка разрешённых доменов в LuCI. Регрессионный тест проверяет исходный и поставляемый JavaScript интерфейса.

В версии 2.4.3-canary.5 исправлена публикация списков при наличии служебных community-*.json и других посторонних файлов. Эти файлы сохраняются; проверка обязательных списков и откат при повреждении управляемых файлов остаются включены.

В этой версии добавлен встроенный список **Gemini / AI Studio**. В правиле подключения выберите нужный VPN-узел (например, Moscow XHTTP), добавьте этот список и сохраните конфигурацию. Он включает `gemini.google.com`, `aistudio.google.com`, `generativelanguage.google.com`, `alkalimining-pa.googleapis.com` и `proactivebackend-pa.googleapis.com`, вместе с их поддоменами. Список встроен в конфигурацию и не требует скачивания SRS. DNS использует обычный механизм FakeIP Forkop, а соединения идут через выбранный VPN-узел; дальнейшие DNS-правила на сервере настраиваются на самом сервере. Правило не меняет настройки остальных подключений.

Discord можно снова добавить в список сервисов нужного VPN-правила после обновления списков. Исправление публикации устраняет обнаруженную в логе ошибку, из-за которой новая конфигурация с Discord и второй подпиской не применялась.

## Установка одной командой

После публикации тестового релиза для установки на стабильном OpenWrt 25.12 с APK и архитектурой aarch64_cortex-a53 (включая Cudy WR3000U v1) выполните по SSH от root:

```sh
wget -O /tmp/artak-install.sh https://github.com/Menshikovivan/ArtakFork/releases/download/2.4.3-canary.8/artak-install.sh && sh /tmp/artak-install.sh
```

Пакеты backend, LuCI и русской локализации будут доступны в [тестовом релизе этого репозитория](https://github.com/Menshikovivan/ArtakFork/releases/tag/2.4.3-canary.8). Установщик проверяет контрольные суммы SHA256 и сохраняет конфигурацию в `/root/artakfork-backups/`. Локальные APK устанавливаются с разрешением неподписанных пакетов через `apk add --allow-untrusted`.

Контрольные суммы охватывают также зеркальные bootstrap-пакеты. Их происхождение записано в `bootstrap-sources.json`, соответствующие исходники приложены к релизу. Публикация проверяет закреплённые стабильные версии и SHA256 пакетов; отдельная команда `python3 scripts/prepare_artak_bootstrap.py --check-latest` проверяет, появились ли более новые версии.

После обновления перезагрузите страницу LuCI с очисткой кэша браузера (Ctrl+F5), чтобы загрузить новый JavaScript.

Для скачивания и проверки без установки: `sh /tmp/artak-install.sh --check`.

Установщик поддерживает чистую установку: устанавливает sing-box Extended и, если Forkop отсутствует, базовый Forkop, затем ArtakFork. Версии закреплены для совместимости: Forkop 1.0.5 и sing-box Extended 1.14.3-extended-2.7.3. Вышедший позже Forkop 2.0 использует другое ядро и механизм миграции и не включён в этот установщик. Уже установленный Extended этой версии повторно не устанавливается. SNAPSHOT, другие архитектуры и OpenWrt с opkg этим установщиком не поддерживаются. Системные зависимости загружаются из родных репозиториев OpenWrt; пакеты должны соответствовать установленному ядру. Конфликты с другими вариантами sing-box не обходятся принудительным удалением. Встроенная установка обновлений Forkop через старый интерфейс отключена: используйте установщик ArtakFork. Списки маршрутизации и отдельные компоненты сохраняют свои прежние источники.

## Проверка

На Linux/OpenWrt с ucode и модулем fs:

```sh
ucode -L forkop/files/usr/lib tests/subscription_source_entry.uc
```

Workflow `Subscription CI` собирает закреплённую версию ucode и запускает тесты подписок, публикации списков и маршрутизации пяти доменов Gemini при push, pull request или вручную.

## Сборка

IPK/APK собираются исходным `build.sh` на Linux с OpenWrt SDK. Сборка и публикация собственных релизов настроены в `.github/workflows/artak-release.yml`. Версия установщика должна совпадать с версией релиза. Пример:

```sh
bash build.sh 2.4.3-canary.8 dist/ArtakFork
```

Для XHTTP требуется совместимый движок, например sing-box Extended. Удаление фильтра подписок само по себе не добавляет XHTTP в штатный sing-box. Перед установкой необходимо проверить архитектуру и версию OpenWrt.

Исходный `install.sh` сохранён для истории upstream; для ArtakFork используйте только `artak-install.sh` из Releases. Нативный тест парсера и сборка пакетов выполняются в GitHub Actions. Новые функции версии 2.4.3-canary.7 требуют отдельной проверки на реальном роутере.
