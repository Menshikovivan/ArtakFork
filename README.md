# ArtakFork

ArtakFork — форк [Forkop X](https://github.com/Screamshow/forkop-x) для OpenWrt с поддержкой HTTPS-подписок разных провайдеров, правилами маршрутизации и интерфейсом LuCI.

Проект основан на Forkop X, Forkop и [Podkop](https://github.com/itdoginfo/podkop). Это самостоятельная модификация; авторство и лицензия исходного проекта сохранены в [LICENSE](LICENSE).

## Возможности

- Загрузка HTTPS-подписок без ограничения по провайдеру.
- Поддержка XHTTP при использовании совместимого движка, например sing-box Extended. Сама загрузка подписки не добавляет XHTTP в стандартный sing-box.
- Правила маршрутизации для отдельных сервисов и встроенный список **Gemini / AI Studio**.
- Группы узлов с приоритетом основного и резервного подключения. Прямое соединение используется как резерв, только если оно явно добавлено.
- Проверка HTTPS для Gemini, ChatGPT и Discord через выбранный узел или группу. Получение ответа не гарантирует доступность сервиса в вашей стране или работоспособность учётной записи.
- Отчёт после обновления подписок: добавленные, удалённые, переименованные и изменённые соединения, а также доступные причины пропуска записей.

Поддержка AmneziaWG развивается отдельно и пока является **экспериментальной**. Импорт и подключение к вашему серверу могут не работать; проверяйте статус соответствующего релиза и его описание перед установкой.

## Установка

Установщик из основного релиза рассчитан на **стабильный OpenWrt 25.12**, пакетный менеджер `apk` и архитектуру `aarch64_cortex-a53`, включая Cudy WR3000U v1. Другие архитектуры, SNAPSHOT и системы с `opkg` этим установщиком не поддерживаются.

Подключитесь к роутеру по SSH и выполните от имени `root`:

```sh
wget -O /tmp/artak-install.sh https://github.com/Menshikovivan/ArtakFork/releases/download/2.4.3-canary.7/artak-install.sh && sh /tmp/artak-install.sh
```

Это ссылка на проверенный установщик основной ветки версии `2.4.3-canary.7`. Другие сборки, включая экспериментальные, перечислены в [Releases](https://github.com/Menshikovivan/ArtakFork/releases); внимательно читайте их описание и не заменяйте версию в команде, пока нужный релиз не опубликован.

Установщик проверяет SHA256 скачанных файлов и сохраняет резервную копию конфигурации в `/root/artakfork-backups/`. При чистой установке он устанавливает совместимые зависимости, включая закреплённые версии Forkop 1.0.5 и sing-box Extended 1.14.3-extended-2.7.3. Локальные APK устанавливаются с `--allow-untrusted`; их происхождение описано в файле `bootstrap-sources.json` релиза. При конфликтах с другими вариантами sing-box установщик не удаляет их принудительно.

Чтобы проверить загрузку и контрольные суммы без установки, после скачивания выполните:

```sh
sh /tmp/artak-install.sh --check
```

После обновления откройте LuCI и обновите страницу с очисткой кэша браузера (`Ctrl+F5`). Для обновлений используйте установщик ArtakFork: встроенное обновление Forkop через старый интерфейс отключено.

## Настройка

1. Откройте LuCI → **Службы → Forkop X**.
2. Добавьте подписку или ключ и обновите список подключений.
3. Создайте правило, выберите сервисы и нужный VPN-узел или группу.
4. Сохраните и примените настройки, затем проверьте работу сервиса на устройстве.

Для Gemini выберите правило с нужным узлом и добавьте список **Gemini / AI Studio**. Список включает `gemini.google.com`, `aistudio.google.com`, `generativelanguage.google.com`, `alkalimining-pa.googleapis.com`, `proactivebackend-pa.googleapis.com` и их поддомены. DNS использует механизм Forkop; правила DNS на VPN-сервере настраиваются отдельно.

Ссылка на подписку и файлы конфигурации VPN могут содержать доступ к вашим подключениям. Не публикуйте их и удаляйте ключи, токены и адреса подписок из журналов перед отправкой.

## Проверка и сборка

На Linux или OpenWrt с `ucode` и модулем `fs` можно выполнить проверку источников подписок:

```sh
ucode -L forkop/files/usr/lib tests/subscription_source_entry.uc
```

GitHub Actions запускает тесты подписок и другие проверки. Доступные сценарии и их результаты находятся на вкладке [Actions](https://github.com/Menshikovivan/ArtakFork/actions). Виртуальная проверка не заменяет тест на конкретном роутере и конкретном VPN-сервере.

Для сборки пакетов на Linux с OpenWrt SDK:

```sh
bash build.sh 2.4.3-canary.7 dist/ArtakFork
```

Сборка релиза настроена в `.github/workflows/artak-release.yml`; версия установщика должна совпадать с версией релиза. Файл `install.sh` оставлен от upstream для истории; для ArtakFork используйте `artak-install.sh` из соответствующего релиза.
