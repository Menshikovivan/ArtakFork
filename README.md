# ArtakFork

Форк [Screamshow/forkop-x](https://github.com/Screamshow/forkop-x) без ограничения подписок по провайдеру. Базовый коммит: `2a0951294d9cdd24370ff97fc1bc09fcb8b7f484`.

## Изменения

- Удалён список разрешённых доменов: можно добавлять HTTPS-подписки других провайдеров в поддерживаемом формате.
- Сохранены проверки HTTPS, пустого адреса и пробелов внутри URL.
- Пользовательский User-Agent задаётся в настройках элемента подписки и имеет приоритет. Автоматический профиль `INCY/<версия>` сохранён для совместимости.
- Обработка одиночных ключей и XHTTP не изменена.
- Добавлены регрессионный тест и GitHub Actions workflow.

## Проверка

На Linux/OpenWrt с ucode и модулем fs:

```sh
ucode -L forkop/files/usr/lib tests/subscription_source_entry.uc
```

Workflow `Subscription CI` собирает закреплённую версию ucode и запускает тест при push, pull request или вручную.

## Сборка

IPK/APK собираются исходным `build.sh` на Linux с OpenWrt SDK. Зависимости указаны в `.github/workflows/build.yml`. Пример собственной версии:

```sh
bash build.sh 2.4.3 dist/ArtakFork
```

Это пример версии для сборки, а не опубликованный релиз. Для XHTTP требуется совместимый движок, например [forkop-x-engine](https://github.com/Screamshow/forkop-x-engine). Удаление фильтра подписок само по себе не добавляет XHTTP в штатный sing-box. Перед установкой необходимо проверить архитектуру и версию OpenWrt.

Исходный `install.sh`, зеркала, метаданные пакетов и обновление пока унаследованы от Forkop X. Сетевой установщик устанавливает upstream, а его обновления могут заменить изменённый пакет. Собственный канал ArtakFork ещё не настроен. Готовые пакеты и реальное XHTTP-соединение на роутере в этой среде не проверены.

## Происхождение

Основан на Forkop X, Forkop (ранее Podkop Plus) и [Podkop](https://github.com/itdoginfo/podkop). Авторство и лицензии сохранены в исходниках и `LICENSE`. ArtakFork является самостоятельной модификацией и не заявляет о связи с авторами upstream.
